## 一、结论摘要

1. **魔改驱动的本质 = 官方 `.run` 里的内核模块二进制补丁**。所以主面板库里只需要一份**声明式补丁数据**
   （实测约 **1 KB/个**），不需要放任何大文件 —— 仓库配额、镜像、上传限制全部不成问题。
2. **靶点已实测确认**（不是猜的）：解包 580.178.04 后补丁靶点是
   `kernel/nvidia/nv-kernel.o_binary`（112,677,456 字节），另有开核模块版
   `kernel-open/nvidia/nv-kernel.o_binary`（17,319,944 字节）；旧分支（470/535 一代）在 `kernel/nv-kernel.o_binary`。
3. **补丁是"数据"不是"命令"**：清单里只能出现枚举过的动作（`blacklist-nouveau`/`gsp-off`/`initramfs`/`depmod`）
   和声明式补丁块（find/replace 十六进制 + 期望命中数）。**清单被篡改也换不来任意 root 命令**，
   这是相比"跑上游 shell 脚本"的关键安全改进。
4. **三道校验闭环**：① 官方 `.run` 的 `sh --check` + sha256；② 补丁块的命中次数必须等于声明值（版本漂移立即失败）；
   ③ 打完必须等于声明的 `result_sha256`（不相等就拒绝安装）。
5. **下载必须分段并发**：实测整文件直连只有 ~55 KB/s，**8 路 Range 并发到 18 MB/s**（397 MB 约 40 秒），
   且 `us.download.nvidia.com`、`cn.download.nvidia.cn` 都是 403 —— 只有 `download.nvidia.com` 可用。
6. 新增 3 个只读/配置接口（总 12 个）：`drivers.gpu`、`drivers.repo`、`drivers.repo.config`；
   安装复用 `drivers.install`（`kind:"mod"`，异步任务）。
7. **两条真实补丁条目已生成并验证入库**（`drivers/registry.json`）：
   `p1xx-580.178.04`（含 **P104-100/P106-100**）与 `cmp-615.71.09`（含 **CMP 30HX**）；
   补丁输出与上游 `linux.sh` **逐字节一致（4/4 比对通过）**，且仅 1 个补丁块、KB 级数据。

### 2.3 「魔改驱动」的机制与版本矩阵（外部来源，实施前复核）

- 上游用 `nv-kernel.o_binary` 的字节 pattern 补丁开启矿卡 3D 加速；矩阵：P1XX → `580.178.04`（任意显示提供者）；
  CMP 及其它 → 显示由 iGPU/AMD/Turing+ 提供 → `615.71.09`，由 Maxwell–Pascal 提供 → `580.178.04`，
  由 pre-Maxwell 提供 → `470.256.02`（无需补丁）。
- **本机是纯计算用途（不接显示器）** → 按"iGPU/AMD/Turing+/none"列：P1XX = 580.178.04，CMP = 615.71.09。

- CMP 30HX/40HX 建议关闭 GSP 固件（`options nvidia NVreg_EnableGpuFirmware=0`）+ blacklist nouveau；
  CMP 的 x16 PCIe 要硬件焊补件解锁（只显示事实，不参与）。

## 三、补丁数据放主面板库（唯一来源）

### 3.1 目录结构（与系统扩展同一套思路）

```
<主面板库>/
  drivers/
    registry.json           扩展读取的唯一清单（KB 级）
    patches/<id>.patch.json 声明式补丁数据（实测约 1 KB/个）
    README.md               维护说明（已入库）
  tools/
    nvpatch.py              声明式补丁引擎（生成/校验/应用）
    build-driver-registry.py 生成 registry.json
    serve-driver-repo.py    本地冒充主面板库（自测用）
  extensions/drivers/       （P5-1 起）驱动扩展本体：清单 + server.py + 前端产物
```

取用阶梯（扩展后端实现，和面板取扩展清单同一思路）：

1. `https://raw.githubusercontent.com/fongwuyan/RainCough-panel-web/<branch>/drivers/registry.json`
2. 镜像：`https://gh-proxy.com/https://raw.githubusercontent.com/...`（国内可用）
3. 本地目录：`<面板安装目录>/driver-src/drivers`（离线/手放；对应扩展机制的 `extension-src/extensions`）
4. 可选：GitHub token（仅当面板库转私有；**只写不读**，存 `<扩展目录>/.data/repo.json` 0600）

### 3.2 清单 `drivers/registry.json`（示例，路线 A）

```json
{
  "schema": 1,
  "note": "RainCough 面板「驱动」扩展的魔改驱动补丁数据（路线 A）",
  "entries": [
    {
      "id": "p1xx-580.178.04",
      "title": "P1XX 系列 (P102/P104/P106) 魔改补丁 580.178.04",
      "type": "patch-data",
      "card_pci_ids": ["10de:1b07", "10de:1b87", "10de:1bc7", "10de:1c07", "10de:1c09"],
      "card_names": ["P102-100", "P104-100", "P104-101", "P106-100", "P106-090"],
      "arch": ["Pascal"],
      "driver_version": "580.178.04",
      "requires": ["dkms", "linux-headers", "build-essential"],
      "post": ["blacklist-nouveau", "initramfs"],
      "reboot_required": true,
      "notes": "靶点 kernel/nvidia/nv-kernel.o_binary",
      "base": {
        "version": "580.178.04",
        "download_url": "https://download.nvidia.com/XFree86/Linux-x86_64/580.178.04/NVIDIA-Linux-x86_64-580.178.04.run",
        "size_b": 397214534,
        "sha256_expected": "5975a86ee45bffcb626f51ae33d1169b108186a2ea47ad651e72f13fa4b6d6f9",
        "verify": ["sh --check", "sha256"]
      },
      "patch": {
        "path": "drivers/patches/p1xx-580.178.04.patch.json",
        "sha256": "<补丁文件自身的 sha256>",
        "target": "kernel/nvidia/nv-kernel.o_binary",
        "blocks": 7,
        "base_sha256": "5269a23ffba19a17fe16f076463e7ad4151254659441d1711bee6c6221ff6f4b",
        "result_sha256": "<打完后的 sha256>",
        "dry_run_required": true
      }
    }
  ]
}
```

约束（构建器强制校验，不合规条目**直接拒绝并在界面显示原因**，不静默跳过）：

| 字段 | 约束 |
|---|---|
| `type` | `patch-data`（默认）\| `patch-script`（兼容上游 bash，需额外确认）\| `nvidia-run`（**预留，当前不用**） |
| `card_pci_ids` | `^[0-9a-f]{4}:[0-9a-f]{4}$`，至少一个 |
| `driver_version` | 形如 `580.178.04` |
| `post[]` | 只能取 `blacklist-nouveau`、`gsp-off`、`initramfs`、`depmod` |
| `patch.path` | 仓库内相对路径（扩展按来源基址拼 URL，故不是绝对 URL） |
| `patch.base_sha256` / `result_sha256` | 合法 sha256（64 位十六进制） |
| 补丁块 `expect_hits` | ≥1，且必须与实际命中数相等 |

### 3.3 声明式补丁数据（`patches/<id>.patch.json`）

```json
{
  "schema": 1,
  "id": "p1xx-580.178.04",
  "target": "kernel/nvidia/nv-kernel.o_binary",
  "base_sha256": "5269a23ffba19a17fe16f076463e7ad4151254659441d1711bee6c6221ff6f4b",
  "result_sha256": "…",
  "blocks": [
    { "id": "blk-1", "find_hex": "…", "replace_hex": "…", "expect_hits": 1, "note": "上游 pattern 1" }
  ]
}
```

等长替换（find/replace 同长度）；工具从"原始 + 已魔改"两个文件自动生成块：先取差异区间，再逐步扩上下文直到在原文里唯一
（命中数 >1 就写进 `expect_hits`），最后做**闭环校验**（重打结果必须逐字节等于魔改版）。

## 五、安装流程（路线 A）

### 5.1 复用 `drivers.install`，`kind:"mod"`

`precheck` 计划增补：

```json
{ "kind": "mod", "entry_id": "p1xx-580.178.04",
  "source": { "repo": "panel:fongwuyan/RainCough-panel-web", "branch": "main",
              "manifest_url": "https://raw.githubusercontent.com/…/drivers/registry.json", "used": "direct|mirror|local" },
  "base": { "download_url": "https://download.nvidia.com/XFree86/Linux-x86_64/580.178.04/NVIDIA-Linux-x86_64-580.178.04.run",
            "size_b": 397214534, "sha256_expected": "5975a86e…", "verify": ["sh --check", "sha256"],
            "download": { "mode": "range-parallel", "connections": 8, "resume": true } },
  "patch": { "path": "drivers/patches/p1xx-580.178.04.patch.json", "sha256": "…",
             "target": "kernel/nvidia/nv-kernel.o_binary", "blocks": 7,
             "base_sha256": "5269a23f…", "result_sha256": "…", "dry_run_required": true },
  "prereq": [ "dkms", "linux-headers-<kver>", "build-essential" ],
  "conflicts": [ { "pkg": "nvidia-driver", "version": "535.309.01", "action": "remove" } ],
  "modprobe": { "file": "/etc/modprobe.d/rc-drivers.conf",
                "lines": [ "blacklist nouveau", "options nouveau modeset=0" ] },
  "post": [ "blacklist-nouveau", "initramfs" ],
  "side_effects": { "initramfs": true, "reboot_required": true, "display_may_break": false },
  "rollback": { "uninstaller": "/usr/bin/nvidia-uninstall", "restore_deb": "apt-get install nvidia-driver",
                "keep_download": true, "backup_required": true },
  "requires_confirm": ["mod-driver-install", "reboot-required"] }
```

### 5.2 执行序列（异步任务；每步写审计）

1. **备份**：`/etc/modprobe.d`、`/etc/modules-load.d`、`/etc/modules`、`/etc/default/grub`（快照，不改）、
   `dpkg -l 'nvidia*' 'libnvidia*'`、`lsmod | grep -E 'nvidia|nouveau'`、`nvidia-smi -q`（若有）。
2. **前置**：`apt-get install -y --no-install-recommends dkms linux-headers-$(uname -r) build-essential`（按需）。
3. **取官方 `.run`**：**8 路 Range 并发**下载到 `<扩展目录>/.data/nvidia/`（续传、单段重试、段大小 8–32MB）→
   拼接 → sha256 与清单比对（不符即删并中止）→ `sh <run> --check`。
4. **解包**：`sh <run> --extract-only` → `NVIDIA-Linux-x86_64-<ver>/`；定位 `patch.target`（不存在即中止并报路径）。
5. **打补丁**：取补丁 JSON（sha256 校验）→ 逐块找 pattern，**命中数必须相等**（否则中止，报"驱动版本与补丁不匹配"）→
   替换 → 结果 sha256 必须等于 `result_sha256`（否则拒绝写入）→ 原子写入（临时文件 + rename，原文件备份 `.orig-<sha8>`）
   → 出补丁报告（每块命中次数/偏移/改动字节数）。
6. **移除冲突包**：按 `conflicts` 执行 `apt-get remove --purge <pkg...>`。
7. **安装**：解包目录里 `./nvidia-installer --silent --no-questions --ui=none --dkms`
   （日志 `/var/log/nvidia-installer.log`）。
8. **收尾（固定枚举动作）**：写托管 `/etc/modprobe.d/rc-drivers.conf`（`blacklist nouveau`；CMP 30HX/40HX 追加
   GSP 关闭行）→ `depmod -a` → `update-initramfs -u -k all`。
9. **校验**：`nvidia-smi -L`、`nvidia-smi --query-gpu=name,driver_version,compute_cap,memory.total --format=csv`、
   `nvidia-smi -q | grep -i gsp`、`/proc/driver/nvidia/version`、`dkms status`。
10. **收尾**：标记 `reboot_required`（**不自动重启**）；保留 `.run` 缓存（换补丁/换版本不用重下 397MB）。

### 5.3 退路（三条，都在界面里）

1. `[官方卸载]` `/usr/bin/nvidia-uninstall --silent` → 恢复托管文件 → `update-initramfs -u -k all`；
2. `[回 Debian 包]` `apt-get install nvidia-driver`（显示将安装版本）；
3. `[重打补丁]` 用缓存 `.run` + 原始靶点备份重跑（无需重新下载，也不怕装坏）。

## 六、安全护栏

| 规则 | 实现点 |
|---|---|
| 补丁数据不能注入命令 | `type` 只有固定实现；`post[]` 只有四个枚举动作；块只有 find/replace 十六进制；无 shell、无脚本执行 |
| 三层校验闭环 | `.run` 的 `--check` + sha256；块命中数；结果 sha256 必须匹配 |
| 版本漂移立即失败 | 靶点 sha256 与 `base_sha256` 不符 → 拒绝（拿错版本驱动不会打出半残文件） |
| 原子写入 + 自动备份 | 临时文件 + rename；原文件备份 `.orig-<sha8>`；失败不留半成品 |
| Secure Boot 开 → 拒绝 | 未签名内核模块无法加载；只给可复制命令，不代签 MOK |
| 改动前必备份 | 备份失败即中止；退路三条 |
| 不自动重启 / 不改 GRUB / 不刷 vBIOS / 不焊接 | GSP 的 cmdline 版本只给可复制命令；硬件操作只显示事实 |
| 只写自己的文件 | `/etc/modprobe.d/rc-drivers.conf`、`/etc/modules-load.d/rc-drivers.conf` |
| 只从可信来源取 | 官方 `download.nvidia.com` + 主面板库 raw（github/gh-proxy）；清单里的 `patch.path` 是相对路径，禁止跳域 |
| 可选强校验 | 清单支持 GPG detached 签名 + pin 指纹（默认关） |

## 十、装机顺序（目标机器还没有面板）

1. 装 **Debian 12（推荐）或 Ubuntu 22.04**，**关闭 Secure Boot**（魔改驱动是未签名内核模块）。
2. 装面板：`curl -fsSL https://gh-proxy.com/https://raw.githubusercontent.com/fongwuyan/RainCough-panel-web/v1.0.0/install.sh | bash`
   （版本号仍 1.0.0）。
3. 面板 →「系统扩展」→ 安装 **drivers** 扩展（装完自动生成 `rc-ext-drivers.service` 并注册接口）。
4. 「驱动」页 → 只读体检（内核/headers/dkms/Secure Boot/卡是否识别/是否已有 nouveau 占用）。
5. 同步补丁清单（默认来源 = 主面板库，镜像自动回退）→ 看清单条目是否覆盖你的卡。
6. 预检 → 确认安装前置（dkms/headers/build-essential）→ 预检 → 确认安装魔改驱动。
7. **重启** → 复检：`nvidia-smi` 认卡、计算能力 6.1/7.5/8.6、显存与链路。
8. （可选，默认不做）容器直通 `nvidia-container-toolkit`：需要加 NVIDIA 官方仓库，与"不加第三方仓库"护栏冲突，
   **要你明确同意才做**。
