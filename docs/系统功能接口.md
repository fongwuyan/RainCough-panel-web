# 系统功能接口(system.*)

> 主系统内置 Provider「system」提供的接口, 任何插件页/系统页/其他插件均可按可见性调用。
> 入口: 「接口总览」`source=system`; 试调用: `POST /api/interfaces/<id>/invoke`。
> 实现: `cmd/raincough/sysproviders.go`(基础 10) + `cmd/raincough/sysproviders_ext.go`(60)。

## 调用方式

```
POST /api/interfaces/system.<块>.<方法>/invoke
Content-Type: application/json
{"params": {...}, "timeout_ms": 0}
```

- 只读接口 `visibility=all`; 管理接口(写/启停/安装/删除)`visibility=main`(仅主系统 UI)。

## 已知边界(实测)

- `system.sys.cron.get` 普通用户(user=f)读 `/var/spool/cron/crontabs/*` 被权限拒绝 → 需 sudo 或仅用 user=f 空结果。
- `system.sys.sshkeys.get` 需指定 `user`(root 无权限, f 可读)。
- 危险能力(关机/重启/apt upgrade/卸载根/快照创建/清理执行)当前**未以接口暴露**(只在维护手册里做负向验证), 保持安全边界。
