## 1. 迁移方法(新插件可复用)

```bash
python tools/migrate-plugin-v4.py plugins/<name> -o v4-out/<name>
```

| 项 | 动作 |
|---|---|
| 后端 | 保留 v3 `server.py`, `server_v4.py` `import server as M` 复用逻辑, `@rc.interface("plugin.method")` 暴露接口 |
| 文件输入 | 前端上传统一 base64 data URL → 插件解码 |
| 产物下载 | 插件写 `work/`, 主系统 `/api/plugins/<name>/work/<session>/<file>` 代发 |
| 数据 | 继续使用插件自身 `data/`(接口库不接管数据) |
| 前端 | `frontend/plugin.js` 按 `__rcPluginV4__` 契约, `node tools/build-plugin-frontend.js <name>`, 产物入 `assets/` |
| systemd | 独立单元, `User=f`, `Restart=always`, 无端口(SDK 读 `.rc.endpoint`/env `RC_ENDPOINT`) |
| 依赖 | 复制 `interface/sdk/backend-python/rcplugin.py` 进插件目录 |
