## 四、部署流程(当前标准)

```bash
# 本地: 打包(仓库根目录)
tar --exclude='.git' --exclude='.go' --exclude='.tmp' -czf /tmp/rc-src.tar.gz cmd internal go.mod go.sum
tar --exclude='web' -czf /tmp/rc-pub.tar.gz public        # 前端已先 vite build(输出到 public)
# 上传: ssh_upload /tmp/rc-src.tar.gz → /tmp/rc-src.tar.gz; rc-pub.tar.gz 同理
```

```bash
# 宿主: 部署(先备份)
cd ~/raincough-dev
TS=$(date +%Y%m%d-%H%M%S); mkdir -p backup-pre-$TS
cp -a raincough backup-pre-$TS/raincough.bin; cp -a public backup-pre-$TS/public
cp -a data/rc.db backup-pre-$TS/rc.db 2>/dev/null || true
tar -xzf /tmp/rc-src.tar.gz; tar -xzf /tmp/rc-pub.tar.gz
export PATH=$HOME/go-tool/go/bin:$PATH
go build -o raincough.new ./cmd/raincough
mv raincough raincough.pre-$TS; mv raincough.new raincough
#   ⚠️ 数据库迁移(仅当从 旧 DSN data/data/rc.db 升级时):
#   [ -f data/data/rc.db ] && mv data/data/rc.db data/rc.db && rmdir data/data 2>/dev/null
sudo systemctl restart raincough.service && sleep 12
# 清理 public/assets 残留(只留 index.html 引用的)
REFJS=$(grep -oE 'assets/index-[^"]+\.js' ../public/index.html | head -1)  # 在 ~/raincough-dev
cd public/assets && find . -maxdepth 1 -type f ! -name "$(basename $REFJS)" ! -name "$(basename $REFCSS)" -delete
```

备用回滚: `backup-pre-*` 内有二进制/前端/数据库; 直接复制回并重启即可。

## 六、Git 要点(教训)

- 打包用 `git archive` / 显式文件列表(新文件易漏)。
- 新 .go/.vue 若被忽略规则挡住需 `git add -f`。
- **禁用 PowerShell `Set-Content` 写中文**(GBK 损坏), 一律用 write/edit 工具。
- 远程命令用脚本文件(scp → bash /tmp/x.sh)或单引号包裹, 避免内联双引号/换行破坏 JSON。
